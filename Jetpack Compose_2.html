🚀 Jetpack Compose

Полный справочник по синтаксису для Android-разработчиков

📐 1. Философия и основы

Что такое Jetpack Compose?

Jetpack Compose — это декларативный фреймворк для создания UI на Android. Вы описываете что должно быть показано, а Compose сам решает как это отрисовать.

Ключевая идея: UI — это функция от состояния.
UI = f(state)

Аннотация @Composable

Все функции, которые описывают UI, должны быть помечены аннотацией @Composable. Это позволяет Compose отслеживать их и перерисовывать при изменении состояния.

@Composable fun MyScreen() { // UI-код здесь }

Функция setContent

class MainActivity : ComponentActivity() { override fun onCreate(savedInstanceState: Bundle?) { super.onCreate(savedInstanceState) setContent { // Здесь начинается ваш Compose-код MyAppTheme { MyScreen() } } } }

✨ 13. Анимации

13.1 AnimatedVisibility — появление/исчезновение

var visible by remember { mutableStateOf(true) } AnimatedVisibility( visible = visible, enter = fadeIn() + slideInVertically() + scaleIn(), exit = fadeOut() + slideOutVertically() + scaleOut() ) { Box( modifier = Modifier .size(200.dp) .background(Color.Blue) ) } Button(onClick = { visible = !visible }) { Text("Переключить") }
Доступные анимации входа/выхода:
fadeIn(), fadeOut() — появление/исчезновение
slideInHorizontally(), slideInVertically() — скольжение
scaleIn(), scaleOut() — масштабирование
expandIn(), expandOut() — расширение
shrinkIn(), shrinkOut() — сжатие

13.2 animate*AsState — анимация значений

var isExpanded by remember { mutableStateOf(false) } // Анимация цвета val backgroundColor by animateColorAsState( targetValue = if (isExpanded) Color.Blue else Color.Red, animationSpec = tween(durationMillis = 500) ) // Анимация размера val size by animateDpAsState( targetValue = if (isExpanded) 200.dp else 100.dp, animationSpec = spring(stiffness = Spring.StiffnessLow) ) // Анимация позиции val offset by animateOffsetAsState( targetValue = if (isExpanded) Offset(100f, 100f) else Offset(0f, 0f) ) Box( modifier = Modifier .size(size) .background(backgroundColor) .offset { IntOffset(offset.x.toInt(), offset.y.toInt()) } .clickable { isExpanded = !isExpanded } )
Доступные animate*AsState:
animateFloatAsState, animateDpAsState, animateColorAsState,
animateOffsetAsState, animateSizeAsState, animateIntAsState

13.3 Animatable — ручное управление анимацией

val animatable = remember { Animatable(0f) } LaunchedEffect(Unit) { animatable.animateTo( targetValue = 1f, animationSpec = tween(durationMillis = 1000) ) } // Анимация с прерыванием Button(onClick = { if (animatable.isRunning) { animatable.stop() // остановить } animatable.snapTo(0f) // мгновенно установить }) { Text("Сбросить") }

13.4 AnimatedContent — анимация смены контента

var contentIndex by remember { mutableStateOf(0) } AnimatedContent( targetState = contentIndex, transitionSpec = { slideIntoContainer(AnimatedContentScope.SlideDirection.Left) with slideOutOfContainer(AnimatedContentScope.SlideDirection.Right) } ) { index -> when (index) { 0 -> Text("Первый экран", fontSize = 24.sp) 1 -> Text("Второй экран", fontSize = 24.sp) else -> Text("Третий экран", fontSize = 24.sp) } }

13.5 Crossfade — плавное переключение

var state by remember { mutableStateOf("loading") } Crossfade(targetState = state, animationSpec = tween(500)) { currentState -> when (currentState) { "loading" -> CircularProgressIndicator() "success" -> Text("Загружено!", color = Color.Green) "error" -> Text("Ошибка!", color = Color.Red) } }

13.6 InfiniteTransition — бесконечные анимации

val infiniteTransition = rememberInfiniteTransition() val rotation by infiniteTransition.animateFloat( initialValue = 0f, targetValue = 360f, animationSpec = infiniteRepeatable( animation = tween(2000, easing = LinearEasing) ) ) Image( painter = painterResource(id = R.drawable.icon), contentDescription = null, modifier = Modifier .size(64.dp) .graphicsLayer { rotationZ = rotation } )

🤌 14. Работа с жестами

14.1 clickable — простые клики

14.2 combinedClickable — множественные жесты

14.3 draggable — перетаскивание

var offsetX by remember { mutableStateOf(0f) } Box( modifier = Modifier .size(100.dp) .background(Color.Blue) .offset { IntOffset(offsetX.toInt(), 0) } .draggable( orientation = Orientation.Horizontal, state = rememberDraggableState { delta -> offsetX += delta } ) )

14.4 swipeable — свайп (смахивание)

var swipeState by remember { mutableStateOf(0f) } val anchors = mapOf(0f to 0, 300f to 1, -300f to -1) val swipeableState = rememberSwipeableState(0, value = swipeState) Box( modifier = Modifier .size(200.dp, 100.dp) .background(Color.Gray) .swipeable( state = swipeableState, anchors = anchors, orientation = Orientation.Horizontal ) ) { Text( text = "Свайпни меня", modifier = Modifier.align(Alignment.Center) ) }
Дополнительные жесты: scrollable — прокрутка, transformable — масштабирование + поворот, pointerInput — низкоуровневая обработка касаний

14.5 pointerInput — низкоуровневая обработка

var position by remember { mutableStateOf(Offset(0f, 0f)) } Box( modifier = Modifier .fillMaxSize() .pointerInput(Unit) { detectDragGestures { change, dragAmount -> change.consume() position += dragAmount } } ) { Box( modifier = Modifier .size(50.dp) .background(Color.Red) .offset { IntOffset(position.x.toInt(), position.y.toInt()) } ) }
Доступные detect-функции:
detectTapGestures — касания
detectDragGestures — перетаскивание
detectTransformGestures — масштабирование + поворот
detectScrollGestures — прокрутка

⚙️ 15. Кастомные компоненты (Custom Views)

15.1 @Composable — композиция существующих компонентов

@Composable fun CustomCard( title: String, subtitle: String, modifier: Modifier = Modifier, onClick: () -> Unit = {} ) { Card( modifier = modifier .fillMaxWidth() .padding(8.dp) .clickable { onClick() }, elevation = CardDefaults.cardElevation(4.dp) ) { Column(modifier = Modifier.padding(16.dp)) { Text(text = title, fontWeight = FontWeight.Bold, fontSize = 18.sp) Text(text = subtitle, color = Color.Gray, fontSize = 14.sp) } } } // Использование CustomCard( title = "Заголовок", subtitle = "Описание карточки", onClick = { /* действие */ } )

15.2 Layout — кастомный лейаут

@Composable fun CustomFlowLayout( modifier: Modifier = Modifier, content: @Composable () -> Unit ) { Layout( content = content, modifier = modifier ) { measurables, constraints -> // Измеряем все дочерние элементы val placeables = measurables.map { measurable -> measurable.measure(constraints) } // Вычисляем ширину и высоту val width = constraints.maxWidth var currentX = 0 var currentY = 0 var maxHeightInRow = 0 // Размещаем элементы как flow-лейаут layout(width, height) { placeables.forEach { placeable -> if (currentX + placeable.width > width) { currentX = 0 currentY += maxHeightInRow + 8 maxHeightInRow = 0 } placeable.placeRelative(x = currentX, y = currentY) currentX += placeable.width + 8 maxHeightInRow = maxOf(maxHeightInRow, placeable.height) } } } }
Внимание: Кастомные лейауты сложны в реализации. В большинстве случаев достаточно использовать встроенные Row, Column, Box и FlowRow.

15.3 Canvas — рисование графики

Canvas(modifier = Modifier.fillMaxSize()) { // Рисуем круг drawCircle( color = Color.Blue, radius = 100f, center = center ) // Рисуем линию drawLine( color = Color.Red, start = Offset(0f, 0f), end = Offset(size.width, size.height), strokeWidth = 5f ) // Рисуем прямоугольник drawRect( color = Color.Green, topLeft = Offset(50f, 50f), size = Size(100f, 100f), style = Stroke(width = 4f) ) // Рисуем текст drawContext.canvas.nativeCanvas.apply { val paint = android.graphics.Paint().apply { color = android.graphics.Color.WHITE textSize = 40f } drawText("Привет!", 200f, 200f, paint) } }
Доступные функции draw:
drawCircle, drawRect, drawLine, drawPath, drawArc,
drawPoints, drawImage, drawRoundRect, drawOval

15.4 Modifier.composed — переиспользуемые модификаторы

fun Modifier.elevatedCard( elevation: Dp = 8.dp, shape: Shape = RoundedCornerShape(12.dp) ): Modifier = this .shadow(elevation, shape) .background(Color.White, shape) .padding(16.dp) // Использование Text( text = "Карточка", modifier = Modifier .fillMaxWidth() .elevatedCard() .clickable { /* действие */ } )

🔄 16. Интеграция с View-системой

16.1 AndroidView — Compose внутри View

// Добавляем старый View в Compose AndroidView( factory = { context -> TextView(context).apply { text = "Я старый TextView из XML-мира" textSize = 20f setTextColor(android.graphics.Color.BLACK) } }, modifier = Modifier.fillMaxWidth(), update = { view -> // Обновление View при изменении состояния view.text = "Обновленный текст" } )

16.2 AndroidViewBinding — загрузка XML-разметки

// Добавляем XML-разметку в Compose AndroidViewBinding( factory = { inflater, parent -> ActivityMainBinding.inflate(inflater, parent, false) }, modifier = Modifier.fillMaxSize() ) { binding -> // Настройка View из XML binding.tvTitle.text = "Заголовок из XML" binding.btnClick.setOnClickListener { binding.tvTitle.text = "Кнопка нажата в XML-мире!" } }
Требует зависимости: implementation "androidx.compose.ui:ui-viewbinding:1.6.0"

16.3 ComposeView — View внутри Compose

// В старом XML-лейауте <androidx.compose.ui.platform.ComposeView android:id="@+id/composeView" android:layout_width="match_parent" android:layout_height="wrap_content" /> // В Activity: val composeView = findViewById<ComposeView>(R.id.composeView) composeView.setContent { MyAppTheme { Text("Я из Compose внутри XML!") } }

16.4 ComposeView в RecyclerView

class ComposeAdapter : RecyclerView.Adapter<ComposeAdapter.ViewHolder>() { override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): ViewHolder { val composeView = ComposeView(parent.context) return ViewHolder(composeView) } override fun onBindViewHolder(holder: ViewHolder, position: Int) { holder.composeView.setContent { MyAppTheme { Card(modifier = Modifier.fillMaxWidth().padding(8.dp)) { Text( text = "Элемент #$position", modifier = Modifier.padding(16.dp) ) } } } } class ViewHolder(val composeView: ComposeView) : RecyclerView.ViewHolder(composeView) }
Оптимизация: При использовании ComposeView в RecyclerView рекомендуется вызывать composeView.disposeComposition() в onViewRecycled() для избежания утечек памяти.

16.5 Обмен данными между View и Compose

// Передаём данные из View в Compose val composeView = findViewById<ComposeView>(R.id.composeView) composeView.setContent { val data by viewModel.data.observeAsState() MyScreen(data = data) } // Вызываем действие из Compose в View @Composable fun MyScreen( data: String, onAction: () -> Unit = {} ) { Button(onClick = onAction) { Text("Нажми, чтобы вызвать действие в View") } } // В Activity передаём лямбду composeView.setContent { MyScreen( data = "Данные из ViewModel", onAction = { // выполнить действие в Activity } ) }
