Пошаговое руководство по созданию 3 версий тестового калькулятора

Kotlin + Jetpack Compose + Material 3

Практическое руководство на основе предоставленного исходного материала: от базовой компоновки Row/Column до интерфейса Material 3 с LazyVerticalGrid и GridItemSpan.

1. Что создаём

Руководство предусматривает три последовательные версии тестового калькулятора.

ВерсияОсновной подходЧто изучаем
V1Row + ColumnБазовые строительные блоки Compose и Modifier.weight()
V2LazyVerticalGridГенерацию интерфейса из списка данных
V3Material 3 + GridItemSpanТемизацию, категории кнопок и элементы разной ширины
Важно: исходный материал прежде всего посвящён UI. В обработчиках кнопок логика вычислений обозначена как «логика позже», поэтому эти версии следует рассматривать как тестовые интерфейсы.

2. Настройка проекта

Шаг 1. Создайте новый проект

  1. Откройте Android Studio.
  2. Выберите New Project.
  3. Выберите шаблон Empty Activity с Jetpack Compose.
  4. Назовите проект, например CalculatorUIPractice.
  5. Выберите Kotlin.
  6. Нажмите Finish.

Шаг 2. Откройте MainActivity.kt

Основной UI размещается внутри или рядом с Compose-функциями. Для тестирования версий достаточно менять вызов внутри setContent:

CalculatorV1()

на:

CalculatorV2()

или:

CalculatorV3()

3. Версия 1 — основа: Row и Column

Цель V1

Понять работу вертикального Column, горизонтального Row и Modifier.weight(). Кнопки здесь создаются вручную.

Шаг 1. Создайте CalculatorV1

@Composable
fun CalculatorV1() {
    // Здесь будет код калькулятора
}

Шаг 2. Создайте основной Column

Column(
    modifier = Modifier
        .fillMaxSize()
        .padding(16.dp)
) {
    // Дисплей и клавиатура
}

fillMaxSize() занимает весь экран, а padding(16.dp) создаёт отступы от краёв.

Шаг 3. Добавьте дисплей

Text(
    text = "0",
    fontSize = 64.sp,
    textAlign = TextAlign.End,
    modifier = Modifier
        .fillMaxWidth()
        .weight(2f)
        .padding(bottom = 16.dp),
    maxLines = 1
)

Дисплей получает weight(2f), то есть две части доступного вертикального пространства.

Шаг 4. Создайте область клавиатуры

Column(
    modifier = Modifier.weight(3f),
    verticalArrangement = Arrangement.spacedBy(8.dp)
) {
    // Ряды кнопок
}

Получается соотношение: дисплей — 2 части, клавиатура — 3 части.

Шаг 5. Добавьте ряд кнопок

Row(
    horizontalArrangement = Arrangement.spacedBy(8.dp),
    modifier = Modifier.weight(1f)
) {
    CalcButtonV1("7", Modifier.weight(1f))
    CalcButtonV1("8", Modifier.weight(1f))
    CalcButtonV1("9", Modifier.weight(1f))
    CalcButtonV1("÷", Modifier.weight(1f))
}

Все четыре кнопки получают одинаковый вес и поэтому занимают одинаковую ширину.

Шаг 6. Создайте компонент кнопки

@Composable
fun CalcButtonV1(
    label: String,
    modifier: Modifier = Modifier
) {
    Button(
        onClick = { /* Логика будет позже */ },
        modifier = modifier.fillMaxHeight(),
        shape = MaterialTheme.shapes.medium
    ) {
        Text(
            text = label,
            fontSize = 24.sp
        )
    }
}

Шаг 7. Создайте остальные ряды

Шаг 8. Подключите V1

Проверка V1: должен отображаться большой дисплей и клавиатура из рядов одинаковых кнопок. Нажатие пока не выполняет вычислений.

4. Версия 2 — управляемая данными сетка

Цель V2

Вместо ручного создания каждой кнопки используется список данных и LazyVerticalGrid. Это отделяет данные от UI и уменьшает количество повторяющегося кода.

Шаг 1. Определите список кнопок

val buttons = listOf(
    "C", "±", "%", "÷",
    "7", "8", "9", "×",
    "4", "5", "6", "-",
    "1", "2", "3", "+",
    "0", ".", "="
)

Шаг 2. Создайте CalculatorV2

@Composable
fun CalculatorV2() {
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp)
    ) {
        // Дисплей и сетка
    }
}

Шаг 3. Добавьте дисплей

val displayText = "123.45"

Text(
    text = displayText,
    fontSize = 64.sp,
    modifier = Modifier
        .fillMaxWidth()
        .weight(1f)
        .padding(16.dp),
    textAlign = TextAlign.End,
    maxLines = 1
)

Шаг 4. Создайте LazyVerticalGrid

LazyVerticalGrid(
    columns = GridCells.Fixed(4),
    modifier = Modifier.weight(3f),
    verticalArrangement = Arrangement.spacedBy(8.dp),
    horizontalArrangement = Arrangement.spacedBy(8.dp)
) {
    items(buttons) { label ->
        Button(
            onClick = { /* Логика позже */ },
            modifier = Modifier
                .height(70.dp)
                .fillMaxWidth(),
            shape = MaterialTheme.shapes.medium
        ) {
            Text(
                text = label,
                fontSize = 24.sp
            )
        }
    }
}

Шаг 5. Подключите V2

setContent {
    CalculatorV2()
}
Проверка V2: сетка должна содержать четыре колонки, а кнопки должны автоматически создаваться из списка buttons. Изменение списка должно менять состав UI.

5. Версия 3 — профессиональный Material 3 UI

Цель V3

Добавляются Material 3, категории кнопок, тематические цвета и возможность сделать кнопку «0» шириной в две колонки.

Шаг 1. Создайте модель кнопки

data class CalcButton(
    val label: String,
    val span: Int = 1,
    val type: ButtonType = ButtonType.NUMBER
)

Теперь каждая кнопка имеет название, ширину в колонках и тип.

Шаг 2. Создайте ButtonType

enum class ButtonType {
    NUMBER,
    OPERATOR,
    UTILITY,
    EQUALS
}
ТипПример
NUMBER0–9
OPERATOR+, -, ×, ÷
UTILITYC, ±, %
EQUALS=

Шаг 7. Реализуйте GridItemSpan

items(buttons) { button ->

    val spanModifier = if (button.span > 1) {
        Modifier.gridItemSpan(button.span)
    } else {
        Modifier
    }

    CalculatorButtonV3(
        label = button.label,
        type = button.type,
        modifier = spanModifier.height(72.dp)
    )
}

Для обычной кнопки span = 1. Для кнопки «0» задано span = 2, поэтому она занимает две колонки.

Шаг 9. Определите цвета по типу кнопки

val containerColor = when (type) {
    ButtonType.OPERATOR ->
        MaterialTheme.colorScheme.primaryContainer

    ButtonType.EQUALS ->
        MaterialTheme.colorScheme.primary

    ButtonType.UTILITY ->
        MaterialTheme.colorScheme.secondaryContainer

    ButtonType.NUMBER ->
        MaterialTheme.colorScheme.surfaceVariant
}

Шаг 10. Определите цвет текста

val contentColor = when (type) {
    ButtonType.EQUALS ->
        MaterialTheme.colorScheme.onPrimary

    else ->
        MaterialTheme.colorScheme.onSurface
}

Шаг 11. Создайте Material 3 Button

Button(
    onClick = { /* Логика позже */ },
    modifier = modifier.fillMaxWidth(),
    colors = ButtonDefaults.buttonColors(
        containerColor = containerColor,
        contentColor = contentColor
    ),
    shape = MaterialTheme.shapes.extraLarge
) {
    Text(
        text = label,
        style = MaterialTheme.typography.headlineMedium,
        color = contentColor
    )
}

Шаг 12. Подключите V3

setContent {
    CalculatorUIPracticeTheme {
        Surface(
            modifier = Modifier.fillMaxSize(),
            color = MaterialTheme.colorScheme.background
        ) {
            CalculatorV3()
        }
    }
}
Проверка V3: интерфейс должен использовать Material 3, разные стили кнопок для разных типов и кнопку «0», занимающую две колонки.

7. Пошаговое тестирование

Тест V1

  1. Запустите приложение.
  2. Проверьте заполнение экрана.
  3. Проверьте дисплей.
  4. Проверьте четыре колонки кнопок.
  5. Проверьте равную ширину кнопок.
  6. Убедитесь, что элементы не накладываются.

Тест V2

  1. Замените CalculatorV1() на CalculatorV2().
  2. Запустите приложение.
  3. Проверьте четыре колонки.
  4. Проверьте все элементы списка.
  5. Измените список buttons и убедитесь, что UI меняется.

Тест V3

  1. Замените вызов на CalculatorV3().
  2. Запустите приложение.
  3. Проверьте Material 3 оформление.
  4. Проверьте разные типы кнопок.
  5. Проверьте кнопку «0».
  6. Убедитесь, что «0» занимает две колонки.
  7. Проверьте отображение на разных размерах экрана.

8. Следующие шаги

После успешного прохождения трёх UI-версий проект можно развивать дальше:

  1. Поэкспериментировать с размерами, отступами и цветами.
  2. Проверить интерфейс на разных размерах экрана и при повороте эмулятора.
  3. Использовать Layout Inspector для поиска проблем компоновки.
  4. Добавить анимации нажатий.
  5. Добавить адаптивность для планшетов.
  6. Добавить поддержку тёмной и светлой темы.
  7. Вынести состояние и вычисления в ViewModel.
Важно: следующие шаги выходят за рамки непосредственно приведённого UI-кода трёх версий. В исходном материале ViewModel указана как следующий этап после экспериментов с интерфейсом.

9. Итоговая схема развития

V1 Row + Column ↓ Понимание базовой компоновки ↓ V2 LazyVerticalGrid + List ↓ Разделение данных и UI ↓ V3 Material 3 + ButtonType + GridItemSpan ↓ Профессиональный UI ↓ Следующий этап ViewModel + состояние + вычислительная логика

10. Минимальный способ переключения версий

После создания всех трёх компонентов достаточно менять один вызов:

setContent {
    CalculatorUIPracticeTheme {
        Surface(
            modifier = Modifier.fillMaxSize(),
            color = MaterialTheme.colorScheme.background
        ) {
            CalculatorV3()
            // или CalculatorV1()
            // или CalculatorV2()
        }
    }
}
Руководство подготовлено на основе предоставленного пользователем материала о создании калькулятора на Jetpack Compose и Material 3.
