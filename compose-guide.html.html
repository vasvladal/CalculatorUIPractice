🚀 Jetpack Compose

Полный справочник по синтаксису для Android-разработчиков

📐 1. Философия и основы

Что такое Jetpack Compose?

Jetpack Compose — это декларативный фреймворк для создания UI на Android. Вы описываете что должно быть показано, а Compose сам решает как это отрисовать.

Ключевая идея: UI — это функция от состояния.
UI = f(state)

Аннотация @Composable

Все функции, которые описывают UI, должны быть помечены аннотацией @Composable. Это позволяет Compose отслеживать их и перерисовывать при изменении состояния.

@Composable fun MyScreen() { // UI-код здесь }

Функция setContent

В Activity или Fragment вы передаёте Compose-функцию в setContent.

class MainActivity : ComponentActivity() { override fun onCreate(savedInstanceState: Bundle?) { super.onCreate(savedInstanceState) setContent { // Здесь начинается ваш Compose-код MyAppTheme { MyScreen() } } } }

🧩 2. Модификаторы (Modifier)

Modifier — это самый важный инструмент в Compose. Он отвечает за:

  • Размеры (width, height, size)
  • Отступы (padding)
  • Выравнивание (align, weight)
  • Обработку событий (clickable, combinedClickable)
  • Анимации (animateContentSize)
  • Фон, рамки, тени (background, border, shadow)
Text( text = "Привет!", modifier = Modifier .fillMaxWidth() // ширина на весь экран .padding(16.dp) // отступы 16dp со всех сторон .background(Color.Blue) // синий фон .clickable { /* действие */ } // обработка клика )

📦 3. Базовые компоненты

Text — аналог TextView

Text( text = "Заголовок", fontSize = 24.sp, fontWeight = FontWeight.Bold, color = Color.White, textAlign = TextAlign.Center, maxLines = 2, overflow = TextOverflow.Ellipsis )

Button — аналог Button

Button( onClick = { /* действие */ }, enabled = true, modifier = Modifier.fillMaxWidth(), colors = ButtonDefaults.buttonColors( containerColor = Color.Blue ) ) { Text("Нажми меня") }

Image — аналог ImageView

Image( painter = painterResource(id = R.drawable.icon), contentDescription = "Иконка", modifier = Modifier.size(64.dp), contentScale = ContentScale.Crop )
Для загрузки из интернета используйте rememberAsyncImagePainter из библиотеки Coil

TextField — аналог EditText

var text by remember { mutableStateOf("") } TextField( value = text, onValueChange = { text = it }, label = { Text("Введите имя") }, modifier = Modifier.fillMaxWidth(), singleLine = true, colors = TextFieldDefaults.colors( focusedContainerColor = Color.Transparent ) )

📐 4. Контейнеры (Layouts)

Column — вертикальный LinearLayout

Column( modifier = Modifier.fillMaxSize(), horizontalAlignment = Alignment.CenterHorizontally, verticalArrangement = Arrangement.SpaceEvenly ) { Text("Элемент 1") Text("Элемент 2") }

Row — горизонтальный LinearLayout

Row( modifier = Modifier.fillMaxWidth(), horizontalArrangement = Arrangement.SpaceBetween, verticalAlignment = Alignment.CenterVertically ) { Icon(Icons.Default.Home, null) Text("Главная") }

Box — FrameLayout (наложение)

Box( modifier = Modifier.size(200.dp) ) { Box( modifier = Modifier .fillMaxSize() .background(Color.Red) ) Text( "Поверх", modifier = Modifier.align(Alignment.Center) ) }

📋 5. Списки (Lazy Lists)

LazyColumn и LazyRow — аналоги RecyclerView. Они загружают только видимые элементы, экономя ресурсы.

val items = List(100) { "Элемент #$it" } LazyColumn( modifier = Modifier.fillMaxSize(), contentPadding = PaddingValues(16.dp), verticalArrangement = Arrangement.spacedBy(8.dp) ) { items( items = items, key = { it } // уникальный ключ для каждого элемента ) { item -> Card( modifier = Modifier.fillMaxWidth() ) { Text( text = item, modifier = Modifier.padding(16.dp) ) } } }
Важно: Внутри LazyColumn нельзя использовать другие Lazy-компоненты. Для вложенных списков используйте LazyVerticalStaggeredGrid или обычный Column.

🔄 6. Управление состоянием (State)

mutableStateOf — наблюдаемое состояние

// Вариант 1: с делегированием (рекомендуется) var counter by remember { mutableStateOf(0) } // Вариант 2: без делегирования val counterState = remember { mutableStateOf(0) } Button( onClick = { counter++ } // при изменении UI перерисуется ) { Text("Нажато: $counter") }

remember — запоминание значения

remember сохраняет значение между рекомпозициями. Без него состояние бы сбрасывалось при каждой перерисовке.

// remember без ключей — сохраняется навсегда val value = remember { expensiveCalculation() } // remember с ключами — пересчитывается при изменении ключей val filtered = remember(inputList, filter) { inputList.filter { it == filter } }

rememberSaveable — сохранение при повороте

Аналог onSaveInstanceState. Сохраняет состояние при повороте экрана.

var text by rememberSaveable { mutableStateOf("") }

👆 7. Взаимодействие с пользователем

clickable — обработка кликов

Text( text = "Нажми на меня", modifier = Modifier .clickable { // действие } )

combinedClickable — расширенные клики

Text( text = "Кликни или долго жми", modifier = Modifier .combinedClickable( onClick = { // короткий клик }, onLongClick = { // долгий клик }, onDoubleClick = { // двойной клик } ) )

🎨 8. Темизация (Theming)

MaterialTheme — единый источник стилей

@Composable fun MyAppTheme( darkTheme: Boolean = isSystemInDarkTheme(), content: @Composable () -> Unit ) { val colorScheme = if (darkTheme) { darkColorScheme( primary = Color(0xFFBB86FC), secondary = Color(0xFF03DAC6) ) } else { lightColorScheme( primary = Color(0xFF6200EE), secondary = Color(0xFF03DAC6) ) } MaterialTheme( colorScheme = colorScheme, typography = Typography( headlineLarge = TextStyle( fontFamily = FontFamily.Default, fontWeight = FontWeight.Bold, fontSize = 30.sp ) ), content = content ) }

👀 9. Preview — предпросмотр в IDE

Используйте @Preview для быстрого просмотра UI прямо в Android Studio без запуска эмулятора.

@Preview( name = "Светлая тема", showBackground = true, backgroundColor = 0xFFFFFFFF, device = Devices.PIXEL_6 ) @Composable fun PreviewMyScreen() { MyAppTheme { MyScreen() } }

🧭 10. Навигация (Navigation)

Для навигации используется библиотека navigation-compose.

val navController = rememberNavController() NavHost( navController = navController, startDestination = "home" ) { composable("home") { HomeScreen(navController) } composable("details/{id}") { backStackEntry -> val id = backStackEntry.arguments?.getString("id") DetailsScreen(id) } } // Переход на другой экран Button(onClick = { navController.navigate("details/123") }) { Text("Перейти") }

⏳ 11. Жизненный цикл

В Compose нет onCreate, onStart и т.д. Используйте LaunchedEffect и DisposableEffect.

// Выполняется один раз при появлении LaunchedEffect(Unit) { // действия при входе на экран } // Выполняется при изменении ключа LaunchedEffect(userId) { // загрузить данные для userId } // С очисткой при выходе DisposableEffect(Unit) { // подписка onDispose { // отписка } }

🏗️ 12. Дополнительные компоненты

Card — карточка с Material Design

Card( modifier = Modifier .fillMaxWidth() .padding(8.dp), elevation = CardDefaults.cardElevation(4.dp), colors = CardDefaults.cardColors( containerColor = Color.White ) ) { Text( text = "Контент карточки", modifier = Modifier.padding(16.dp) ) }

Scaffold — стандартный макет экрана

Scaffold( topBar = { TopAppBar( title = { Text("Мое приложение") } ) }, bottomBar = { BottomNavigation { // навигация внизу } }, floatingActionButton = { FloatingActionButton(onClick = {}) { Icon(Icons.Default.Add, null) } } ) { innerPadding -> // основной контент Column(modifier = Modifier.padding(innerPadding)) { Text("Основной контент") } }

AlertDialog — диалоговое окно

var showDialog by remember { mutableStateOf(false) } if (showDialog) { AlertDialog( onDismissRequest = { showDialog = false }, title = { Text("Заголовок") }, text = { Text("Текст диалога") }, confirmButton = { Button(onClick = { showDialog = false }) { Text("OK") } }, dismissButton = { Button(onClick = { showDialog = false }) { Text("Отмена") } } ) }

DropdownMenu — выпадающее меню

var expanded by remember { mutableStateOf(false) } Box { IconButton(onClick = { expanded = true }) { Icon(Icons.Default.MoreVert, null) } DropdownMenu( expanded = expanded, onDismissRequest = { expanded = false } ) { DropdownMenuItem( text = { Text("Пункт 1") }, onClick = { expanded = false } ) DropdownMenuItem( text = { Text("Пункт 2") }, onClick = { expanded = false } ) } }

📝 13. Полезные шаблоны

Обработка загрузки данных

when (state) { is Loading -> CircularProgressIndicator() is Success -> MyContent(state.data) is Error -> Text("Ошибка: ${state.message}") }

Анимация при появлении

AnimatedVisibility( visible = isVisible, enter = fadeIn() + slideInVertically(), exit = fadeOut() + slideOutVertically() ) { Text("Я появляюсь с анимацией!") }

Адаптивный размер

val density = LocalDensity.current val screenWidth = density.configuration.screenWidthDp.dp if (screenWidth > 600.dp) { // планшетный вид Row { ... } } else { // мобильный вид Column { ... } }

Пользовательские типы данных в remember

data class User(val name: String, val age: Int) var user by remember { mutableStateOf(User("Анна", 25)) } Button(onClick = { user = user.copy(age = user.age + 1) }) { Text("Возраст: ${user.age}") }
